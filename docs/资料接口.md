# 资料服务接口

相同片段路径在窗口推进后可能成为 410；尚未发布的片段返回 404，/clock 随同一操作推进。普通预览只列机位，不展开时间线或领取媒体。

清单使用 DASH 命名空间。MP4 样例只保留资料领取需要的容器头，不提供可播放视频；接收端保存并校验原字节，不执行解码。/clock 提供受控来源时钟，片段可用性以该时钟及 MPD 共同说明。

本地服务的资料入口为 `/live.mpd`。`fixtures/ordinary.json` 记录当前可预览的资料；`fixtures/transition.json` 保存资料源连续两个发布日期。调用 `POST /control` 并传入 `{"action":"advance"}` 推进发布日期，`inspect` 返回实际请求记录，`reset` 恢复本地源；控制入口不属于远端标准协议。来源分段、延迟和断连均可用场景条目的 `chunks`、`delayMs`、`disconnect` 配置，不需要依赖实际网络故障。

原件目录采用内容摘要寻址，接收凭据独立记录来源、媒体类型和预览结果。单份资料接收不表示来源范围已经读完，也不推断缺失资料的业务含义。
